# 豆包水印清理器 V2

独立于 `omni/gemini` 的本地图片/视频水印清理实验工具。

## 处理策略

- 自动定位右下角豆包水印区域，识别浅色低饱和字形 mask。
- 默认只修复字形像素，不把整个右下角矩形涂成模糊块。
- 图片使用 PNG 输出，视频按首帧字形 mask 逐帧处理并输出 WebM。
- 所有文件在浏览器本地处理，不上传原素材。

## 本地运行

```powershell
python server.py
```

然后打开 `http://127.0.0.1:4173/`。本地后端存在时，图片和视频都走 OpenCV；直接用静态服务器打开时，图片仍可在浏览器处理，视频会使用降级模式。
